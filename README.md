## How to Run & Show the Demo to the Owner

1. **Direct Offline Demo (No Internet or Server Required):**
   - Double-click on `index.html` in this folder to open the flagship landing page directly in Chrome, Edge, or Brave.
   - Double-click on `menu.html` to show the standalone Digital QR Code Table & Room Menu with instant dish search.
   - Double-click on `rooms.html` to show the dedicated Hotel Accommodations and room tariff showcase.
   - Double-click on `banquets.html` to showcase the Grand Wedding Lawn and AC Banquet Hall.
   - Double-click on `qr-standee.html` to demonstrate the printable Table Tent Card with dynamic table number switcher and print button!

2. **Test on Mobile (Simulating the Customer Experience):**
   - Press `F12` in Chrome/Edge, click the device toggle icon (or `Ctrl + Shift + M`), and select "iPhone 14 Pro" or "Samsung Galaxy".
   - Notice the **sticky floating bottom bar** ("Call", "WhatsApp", "Rooms", "Route", "Plate") designed specifically for highway travelers and diners!

3. **Deploy Free on the Web in 2 Minutes:**
   - **Option A (Netlify Drop):** Go to [netlify.com/drop](https://app.netlify.com/drop) and drag-and-drop the entire `raj-rasoi-hotel-restaurant` folder. You will get a live link like `rajrasoi.netlify.app` within 30 seconds!
   - **Option B (Vercel):** Run `vercel` from this folder or import to GitHub.
   - **Option C (GitHub Pages):** Push to a GitHub repository and turn on GitHub Pages in repository settings.
